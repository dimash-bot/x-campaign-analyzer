How metrics are calculated
Engagements = likes + retweets + quotes + replies + bookmarks
ER = engagements ÷ views
Total budget = sum of X post costs + other spend
Avg CPM = X post costs ÷ views × 1,000
Avg CPE = X post costs ÷ engagements
$ / reg = spend ÷ registrations (per day: that day's post costs; total: total budget)
$ / API user = day's spend ÷ API key users
Reg → API = API key users ÷ registrations
Reg / 1K views = registrations ÷ views × 1,000
Posts with no view count (made before X showed views) are excluded from ER.
Posts are attributed to the day they were posted (UTC) — change "Day" per post to re-attribute.
